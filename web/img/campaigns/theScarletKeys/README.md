# 绯红密钥原创场景资源

使用 OpenAI 内置 image_gen 生成 12 张原创插画，包括战役大厅主视觉、调查牌桌和十关各一张剧情插画。运行素材采用 1536 × 1024 WebP。牌桌使用暗绯色皮革，纸张和密钥放在边缘，中央留出低对比度的放卡区。

[assets.json](assets.json) 记录完整提示词、尺寸、文件大小、SHA-256 和 PNG 原图路径。主题和图片由 [campaign-presentation.js](../../../campaign-presentation.js) 接入。

十关各三首 BGM，共 30 首不同曲目。20 首新增、10 首复用，旧曲复用率为 33.3%。播放顺序和曲目来源见 [关卡 BGM 分配](../../../audio/music/SCENARIO-PLAYLISTS.md#绯红密钥八循环)。
