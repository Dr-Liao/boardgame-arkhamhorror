# 沉没之城原创场景资源

使用 OpenAI 内置 ImageGen 生成 12 张原创环境插画，包括战役大厅主视觉、深海远征牌桌和十关的剧情插画。运行素材为 1536 × 1024 WebP。大厅以海雾、玄武岩和旧铜为主，牌桌中央保留低对比度的放卡区。

[素材清单](assets.json) 记录逐图提示词、PNG 原图相对路径、尺寸、文件大小与 SHA-256。主题和插画由 [campaign-presentation.js](../../../campaign-presentation.js) 接入。

10 个关卡各有三首 BGM，每关两首新增和一首复用，旧曲复用率为 33.3%。播放顺序、来源及授权见 [关卡 BGM 分配](../../../audio/music/SCENARIO-PLAYLISTS.md#沉没之城十循环)。
