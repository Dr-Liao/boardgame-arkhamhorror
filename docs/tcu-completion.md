# 万象无终完成验收

范围为原战役的序章与八章、四段幕间、尾声、377 条卡面记录及各章完整中英文冒险指南。

## 本轮修复

- 普雷斯顿的资源池与家族遗产资源分离；支付可选择来源，卡效果收益、资源损失及旧存档迁移共用引擎接口。
- 反应灵敏可在其他调查员行动之间打出，立即执行一次真实行动，再恢复原调查员与正常行动池。选择使用现有可序列化规则事务。
- 知识就是力量走完整能力执行管线，忽略费用并保留目标、效果及限次规则。
- 美满结局在标记结算前取消数值、符号或自动失败标记，改为结算调查员的旧印。
- 诱敌深入覆盖敌军阶段中由剧本效果发起的移动。
- 机关盒的行动与被击败转交成为跨章节的受控支援规则。
- 崇高利益、聚合幻灭补全核心遭遇组与分支移除；死亡门前的证据由队长分批选择；古怪图形删除错误普通连接。
- 隐秘之名的骷髅奖励进入战役混乱袋；收藏弱点及其升级持久修改个人牌组。
- 每张盲目舞者分别保存虚空位置与每轮强制次数，最短路线平手交由队长选择；动态地图使用实际宇宙坐标。
- 黑色王座的“陷入疯狂”写入精神创伤、调查员状态及战役记录；尾声保留已读正文快照并划掉指定记录。

## 规则来源裁决

幕间四的专家标记采用英文指南及参考执行规则的 **−6**；中文翻译来源的 −7 与两者冲突。阿撒托斯沿用独立全局状态：参考规则的普通敌人匹配器排除 Omnipotent，显式阿撒托斯效果分别读取毁灭、攻击和附属状态。两者的裁决与本轮修复前的逐卡、章节记录保留在 `audit/tcu-completion-review.json`。
