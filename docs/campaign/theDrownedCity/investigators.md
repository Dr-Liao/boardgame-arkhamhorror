# 《沉没之城》调查员与专属依赖

P5 在大厅开放 6 位调查员、8 个可选版本以及 14 张专属依赖。选人和构筑可用性由 `tdcInvestigators` 内容包声明。阿加莎的两种职阶共享席位身份，歌莉娅的循环版和书版也互斥。

| 调查员 | 能力、旧印及专属依赖 |
| --- | --- |
| 玛利翁 `11001` | 少一手部槽。自己的回合每轮一次在打出事件后抽牌，可支付费用打出另一张不同名称的事件。旧印检索牌库顶三张并抽取事件。`11002` 可在自己的事件检定成功后返回手牌。`11003` 给事件追加恐惧费用，可弃三张事件移除。 |
| 卢修斯 `11004` | 躲避成功且领先至少两点可发现线索，每轮一次。旧印按同地点敌人计数。`11005` 首次发现线索时补灵感，花费灵感加技能值并在刚好成功时抽牌。`11006` 在本人回合首次发现线索时造成恐惧并洗回。 |
| 阿加莎 `11007/11008` | 封印、取消或忽略标记后，可在回合结束打出弃牌堆的法术或洞察事件，结算后移出游戏。旧印可取消并重抽标记。`11009` 封印成功检定中的数字标记并用它替换下一次揭示。`11010` 使每次检定额外揭示一枚标记，可花一个行动洗回。 |
| 迈克尔 `11011` | 花费枪械弹药后获得资源，每件枪械每轮一次。旧印可给枪械补一发弹药。`11012` 增加两个枪械手部槽，打出时检索牌库顶九张。`11013` 将枪械洗回牌库，缺少目标时承受伤害并洗回弱点。 |
| 歌莉娅 `11014/98019` | 选择神秘阶段抽取遭遇牌的调查员顺序。查看遭遇牌时可额外查看、处理非精英牌，暗置上限三张，旧印查看牌库顶。循环版 `11015` 以暗置同名副本取消遭遇牌，三张 `11016` 开局进入遭遇牌库。书版 `98020` 以同特质暗置牌降低遭遇检定难度，`98021` 随机结算暗置遭遇牌。 |
| 乔治 `11017` | 手牌上限等于暗置牌数，最多暗置五张。弃牌后可暗置并补牌，每阶段一次。暗置牌可投入检定，旧印抽牌。`11018` 交换暗置牌与等量非弱点手牌，`11019` 清空暗置区或洗回。 |

## 构筑及存档

- 玛利翁的三个可选特质由牌组内容反推，手动提交及自动构筑都校验整副牌能否归于同一个选项。歌莉娅的副职阶沿用大厅的整副牌校验。阿加莎两版和乔治各 35 张，其余各 30 张。
- 迈克尔构筑接受目录的 `fa` 标签、印刷枪械特质或卡文中的 `[[Firearm]]`。签名卡和专属弱点按版本及印刷份数加入牌组。歌莉娅默认采用所选版本的整套专属牌。
- 暗置牌由服务端存储，只向该席位提供牌面，其他席位可见数量。既有的 AI 随机选人池继续用于种子回放。调查员包可在已开放的战役中使用，普通玩家卡归 P6，《沉没之城》的剧本及战役流程归 P7。
