# 三选一选牌模式（暂定）

状态：暂定规则已接入首版实现。此目录专门记录该模式的规则、后续设计与平衡调整；实现入口和验证记录见 [实现说明](implementation.md)。

开局入口：游戏高级设置 → 游戏模式 → 选牌模式（默认普通模式）。选择后展示对应模式的描述。

## 模式概念

提供类似《炉石传说》竞技场的构筑体验：先选择调查员，再通过卡牌三选一组成卡组。选牌界面同步显示当前卡组、费用分布等信息，帮助玩家判断构筑方向。

本模式通过混乱袋与经验收益补偿随机构筑的难度。以下为当前暂定规则，不提供保底。

## 当前暂定规则

### 混乱袋补偿

在正常混乱袋的基础上，额外加入一枚 `+1` 和一枚 `0` 标记。

这两枚标记是模式赠与的标记，必须始终存在，不会被剧本规则移除、替换或改变。战役重建或替换混乱袋时，也须保留这两枚模式标记。

这是模式的混乱袋配置补偿，不表示每完成一关就累计加入两枚标记。

### 初始选牌

先选择调查员，再通过三选一完成初始卡组。初始选牌阶段总共提供 `3` 次免费刷新机会。

不提供底牌或功能保底。

### 可用卡池与重复卡限制

初始选牌、关后免费候选和付费刷新均必须遵守所选调查员的构筑范围，不能出现角色构筑范围外的卡牌。

通常的同名卡数量上限在本模式中取消：只要符合构筑范围，普通卡牌可重复选择任意数量。

例外是明确规定只能有一张的卡牌：卓越卡牌，以及写明“每位调查员只能拥有一张”等单张限制的卡牌，仍须遵守各自的限制，不得通过重复选牌绕过。生成候选与购牌入组时均须检查这些限制。

### 关后经验

每关结束后，以所有相关奖励与调整处理完毕后的本关最终结算经验为基数，先加 `1`，再乘以 `2`：

```text
本关模式经验收益 =（本关最终结算经验 + 1）× 2
```

例如，本关最终结算为 `3` 点经验，则模式收益为 `(3 + 1) × 2 = 8` 点。以最终结算值统一计算，不只翻倍其中的胜利点等奖励。已有的未花费经验不参与本关收益的翻倍。

### 关后升级三选一

升级时机遵守原战役规则。禁止升级的检查点或分段休息窗口不提供选牌、购买或刷新；等到战役允许升级的关间窗口再进行三选一。锁定候选保留到下一次允许升级的窗口。

每关结束后提供一次无需支付刷新费用的升级三选一机会；如果跨关保留了锁定候选，则放弃这次免费刷新机会，继续使用原候选（见“锁定与跨关保留”）。三个卡牌选项的分布如下：

| 位置 | 候选要求 |
| --- | --- |
| 第一个选项 | 必定为 0 经验卡牌 |
| 第二个选项 | 必定为有经验卡牌，即等级大于 0 的卡牌 |
| 第三个选项 | 必定为有经验卡牌，即等级大于 0 的卡牌 |

每组三选一可选择一张卡，也允许跳过。选牌后不自动补充下一组选项；本关还想继续选牌，必须花费经验刷新出新的一组，不刷新就没有后续选牌机会。

允许离开升级界面后随时回来；有足够经验时，可以继续付费刷新。

此处的“0 经验／有经验”指卡牌的经验等级，不是打出卡牌的资源费用。

### 购牌与升级费用

- 0 经验选项可以免费替换入组。
- 有经验选项按实际升级费用收费，支持同名卡升级支付差价。
- 如果卡组中有对应的同名低等级卡，其同名升级卡在刷新时的出现权重提高 `100%`，即在原权重基础上乘以 `2`。加权后仍在合法候选池内统一归一化抽取，不保证出现。
- 刷新费用与购牌费用分开计算：花费经验刷新不会抵扣购牌费用。

### 永久牌与扩容补牌

- 永久牌不占普通牌组张数，直接加入，不替换普通卡；选入时的附加效果照常结算，例如奥术研究的精神创伤。
- 初始选到增加牌组大小的牌后，按新的目标张数继续三选一。
- 关后购入扩容牌后，自动进入“补足牌组”：三个候选均为计入牌组张数的 0 经验卡。每选一张免费生成下一组，直到补齐，即使剩余经验为 0 也可完成。
- 补牌过程中不能锁定或确认准备；主动刷新仍需支付 1 经验。补满后本组选牌结束，不额外赠送升级候选。
- 未达到当前牌组要求时，服务端禁止确认准备和开始关卡。旧存档中的缺牌状态可返回选牌界面补齐。

### 刷新

关后每次刷新花费 `1` 点经验，刷新全部三个选项，不支持只刷新单个位置。初始选牌阶段的三次免费刷新单独计算。

刷新后，新生成的候选仍须符合各位置的经验等级要求。

### 锁定与跨关保留

锁定以整组为单位：三个选项一起锁定，不是单独锁定某张卡、刷新其余位置。

经验不足时，玩家可以保留整组三个选项，下一关结束后回来继续购买；跨关返回时，这三个选项保持不变。

锁定的代价是失去下一关的一次免费刷新机会，不另行发放或暂存该机会。玩家需要在保留当前候选与获得下一关的新候选之间自行取舍。返回后如需换一组，仍可花费 `1` 点经验刷新全部三个选项。

锁定用于保留候选卡牌，不等于已经购买或加入卡组；选择有经验的锁定卡牌时，仍需支付购牌经验。

### 多人独立进度

每位玩家分别拥有自己的初始刷新次数、升级候选、经验、付费刷新与整组锁定记录，彼此独立。

## 界面记录

- 初始流程：选择调查员 → 卡牌三选一 → 查看并完成卡组。
- 选牌时可查看当前卡组与费用构成。
- 初始选牌时显示剩余免费刷新次数。
- 关后升级时显示当前可用经验、三个候选、实际购牌／升级经验费用、刷新费用和整组锁定状态。
- 支持跳过、离开后返回，以及跨关恢复整组候选。
- 锁定时明确提示：保留整组候选将失去下一关的免费刷新机会。
- 界面明确区分卡牌的资源费用与经验费用。
