## 1. 范围、方法与限制

### 1.1 权威范围
- 记录来源：`audit/eote-all-card-acceptance.json`（403 条）+ `audit/eote-scope.json`（8 章、16 共享组、混乱袋、指南来源）；权威卡面文本取 `src/cards/cards-data.js`（英文 `text` / 中文 `textZh` / 背面）。

### 1.2 五维审计标准
| 维度 | 标准 | 判定 |
| --- | --- | --- |
| D1 实现 vs 描述 | 卡面每个印刷子句在真实引擎路径可达 | `implemented / approximation / missing` → `match / approximation / gap` |
| D2 交互可感知 | 选择有提示、自动效果有日志/投影、隐藏信息不泄漏、指南/面板可见 | `perceivable / partial / silent` |
| D3 关卡可跑通 | 真实引擎 setup→幕/议程→地点/遭遇→结局/记录→下一章 | `runnable / stall / blocked` |
| D4 原语规则 | 只用登记原语与 ctx.api、声明即有读点与测试、无卡号分支、近似有披露 | 违规逐条 |
| D5 复用 | 同句模板/同机制复用原语；重印走别名；章节间不复制粘贴 | 复用缺失逐条 |

### 1.3 方法
1. **范围重建**：从 403 条账本 + 文件系统重建权威 scope，生成每卡审阅包（卡面中英 + 条目源码 + 相关测试）与每章源码包（`games/arkhamhorror/docs/edgeOfTheEarth/eote-scan/tools/extract-scope.mjs`）。
2. **机械筛查**（Lead）：条目完整性、打印模板→实现特征、声明字段→引擎读点、同文/克隆、测试覆盖、可感知静态线索、场景完整性、已知偏差、原语合规、**账本证据有效性**、**死钩子扫描**（`games/arkhamhorror/docs/edgeOfTheEarth/eote-scan/screen/`）。
3. **8 名审计员分片逐卡/逐章审计**：调查员 22、玩家卡 60+55、战役卡 48+75+52+91，每卡 `verdict + clauses(file:line) + issues`；战役卡审计员同时追到章节 behavior/definition 消费点。
4. **真实引擎探针**：战役/调查员/关卡审计员用生产组合根（`content/registered.js` + `tests/eote-p8-fixture.mjs`）驱动 `setup/legalMoves/advanceAgenda/advanceAct/遭遇/移动` 等真实路径（探针脚本保留在各 area 下）。
5. **对抗式复核**：对 FatalMirage、调查员、玩家卡 B 三组结论启动独立复核子代理（复核 5 项关键 claim + 随机抽样 issue + 账本独立复算）。
6. **Lead 亲自复核**：对下述 P0 逐一读码/跑探针确认（§3 标注 verifiedBy）。

### 1.4 限制（如实披露）
- 本机 DSH 沙箱禁止 Node 以管道 spawn 子进程：`node --test` 默认、`npm run test:*`、`tools/verify-eote.mjs`、`audit-eote-all-cards/player/investigators` 等工具无法运行；EOTE 专项测试以 `--experimental-test-isolation=none` 单进程实跑，账本类审计用自写复算替代。
- Playwright 浏览器测试无法运行；只对 6 份浏览器账本做了「状态 + 截图路径存在性 + spec 断言」核验（200 张截图路径全部存在）。
- 原扫描时受只读沙箱限制，过程产物与原始日志曾放在项目根；现已统一归档到战役文档目录 `games/arkhamhorror/docs/edgeOfTheEarth/eote-scan/`。
- verdict 是「规则等价性」的人工复核结论，不是官方逐字等价声明；对「近似可接受」的判断存在主观空间，但所有 gap/high 均给 file:line 与复现方式。

### 2.3 结论如何得出（与 P8 口径的差异）
P8 账本的标准是「条目文件存在 + 有测试/功能标题证据 + gates 自洽」；本轮标准是「**印刷规则能在真实引擎路径被触发**」。两者差距由三类系统性缺陷造成：
1. **章节钩子契约不符**：behavior 导出 `scenarioActions/performScenarioAction/chaosTokenValue`，引擎调用 `actions/performAction/resolveChaosToken`；缺 `agendaReveal/actReveal/resolution` → 直接 throw、静默空转或整段规则不可达。
2. **声明即接线被违反**：207 条 `*Rule/flags` 声明在 src+content 无读点；条目写 `implemented:true`、账本写 `verified`。
3. **测试虚绿**：章节测试用 api stub 直调 behavior.*（绕过引擎钩子/legalMoves/advanceAgenda）；P8 campaign/browser 验收用 `finishScenario` 或调试命令跳过章节内游玩。
