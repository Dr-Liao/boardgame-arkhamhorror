## 卡面文本（英文）
```
Fast.
[fast] During a skill test while fighting or investigating, exhaust Ice Pick: You get +1 skill value for this test. If you succeed, you may discard Ice Pick to have this attack deal +1 damage (if you are fighting), or to discover 1 additional clue at your location (if you are investigating).
```

## 条目源码
```js
// 08107 破冰锥（3 级）
// 卡面：快速。
//       [free]攻击或调查时的技能检定期间，横置破冰锥：你本次检定得到技能值+1。
//       如果你成功，你可以弃掉破冰锥来使得本次攻击造成+1伤害(如果你攻击)，或发现你所在地点的额外1个线索(如果你调查)。
//
// 读点：+1 技能值走技能检定内的玩家窗口 + api.addTestPendingBonus(1)；
// 「成功后弃掉本卡换取收益」用第二条 free 能力（弃掉自身费用）+ api.addExtraOnSuccess 近似：
//   调查 → 额外 discoverClue；攻击 → 额外 dealDamage(engaged)。
//
// approximation: 弃置时机是检定窗口（印刷为成功后可选），且攻击收益按「成功后对交战敌人追加 1 伤害」
//   结算而非并入本次攻击伤害；已提交请求 m2-3-08107。
//
// 一张卡一个文件：这张卡的行为只在这里维护。

export default {
  code: '08107',
  fast: true,
  abilities: [
    { kind: 'free', trigger: ['test.beforeCommit', 'test.afterCommit'], duringOwnSkillTest: true,
      label: '横置：本次攻击/调查检定 +1 技能值', cost: { action: false, exhaust: true },
      criteria: ({ state }) => ['fight', 'investigate'].includes(state.skillTest?.actionKind),
      resolve: ({ api }) => api.addTestPendingBonus(1) },
    { kind: 'free', trigger: ['test.beforeCommit', 'test.afterCommit'], duringOwnSkillTest: true,
      label: '弃掉破冰锥：成功时额外 +1 伤害/线索', cost: { action: false, discardSelf: true },
      criteria: ({ state }) => ['fight', 'investigate'].includes(state.skillTest?.actionKind),
      resolve: ({ state, api }) => {
        if (state.skillTest?.actionKind === 'investigate') api.addExtraOnSuccess({ type: 'discoverClue', amount: 1 })
        else api.addExtraOnSuccess({ type: 'dealDamage', amount: 1, target: 'engaged' })
      } },
  ],
  modifiers: [],
}

```
