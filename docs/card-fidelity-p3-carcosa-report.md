## 机制改动

- `agendaDoom` 现在按规则书统计**场上全部毁灭**（密谋 + 敌人/地点/支援/威胁区），`totalDoom` 与其一致；推进时仍只清空密谋上的毁灭。
- `performTest` 新增 `scenarioBehavior.testDifficultyModifier` 全局难度钩子。
- `evadeSuccess` 窗口新增 `successBy`。
- 新增 `engageNoOpportunityAttack`、`attacksCannotBeCancelled`、`onAttackedHorror` 条目字段。
