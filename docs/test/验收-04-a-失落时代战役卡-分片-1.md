- 原因：卡面「如果在你所在地点没有调查员带有指南针，你必须花费 3 资源」是地点级群体检查；实现两条路径（beforeExplore / beforeInvestigate）都只检查 `api.checkSupplies(inv.seat, ...)`（当前调查员本人）。多人局同地点另一名调查员带指南针时仍会被强制收 3 资源，与卡面不符；另该条目 `inv.resources -= 3` 属存量 R1 直写（audit 基线 directStateWrite）。
