## 3. 逐卡失败清单

### 3.1 实现完整性失败（1 张）

**04220 蛇怪** —— 维度：`implementation`
- 卡面：「强制 - 在一个石柱标记被放置在昆扬之口上后：将一张蛇怪洗入遭遇牌库。（每轮最多一次。）」
- 实现：`content/campaigns/theForgottenAge/scenarios/heartOfTheEldersPart1/behavior.js:152-169` 的
  `placePillar()` 只在 **场上有蛇怪** 且弃牌堆/放一边有副本时洗回；卡面没有「场上有蛇怪」前置条件。
  因此「蛇怪已被击败进弃牌堆、场上无蛇怪时又放置石柱标记」这一可达路径上，卡面要求洗回而实现不触发。
- 性质：近似实现，**未在条目/审计账本披露**（`audit/tfa-migration.json` 反而登记
  `literalCardBehavior: true`、`remaining: []`）。
- 证据：`tests/acceptance-04-a-shard3.test.mjs`「04220 蛇怪：石柱标记放到昆扬之口后把一张蛇怪洗入遭遇牌库」
  （只覆盖「场上有蛇怪」路径，正是实现与卡面的差异点）；`behavior.js:152-169`。
- 建议：把「洗回一张蛇怪」改为从弃牌堆/放一边取副本、不依赖场上蛇怪；或在条目用 `simplified/note` 显式披露。

### 3.2 原语设计失败：同句双实现（2 张）

**04215 落入陷阱** / **04216 有毒孢子** —— 维度：`primitives`
- 两张卡同属上下两章共用的 `heart_of_the_elders` 遭遇组，同时出现在
  `heartOfTheEldersPart1` 与 `heartOfTheEldersPart2` 的遭遇牌库；条目
  `src/cards/encounter-entries/theForgottenAge/_shared/heart_of_the_elders/04215.js`、`04216.js`
  只声明 `flags.pitfall` / `flags.spores`，**真正的结算在 behavior.js 各写一份**：
  - part1：`behavior.js:380-410`（落入陷阱）、`411-425 + 571-591`（有毒孢子）；
  - part2：`behavior.js:247-268`（`resolvePitfall`）、`270-304 + 727-735`（`resolvePoisonousSpores`）。
- 违反「同句规则只写一次」；且两处 **失败差值口径不一致**：part1 用 `Math.max(0, 3 - result.value)`，
  part2 用 `Math.max(1, 3 - result.value)`——在「失败且 value≥3」的边界上同样卡牌给不同伤害，
  属迁移规范 §2「口径冲突先裁决」。
- 证据：`tests/acceptance-04-a-shard3.test.mjs` 的 04215/04216 两例（各自章节路径），
  以及 part1/part2 既有测试「落入陷阱…」「有毒孢子…」。
- 建议：主进程先裁决失败差值下限，再把唯一实现迁回单卡条目（`encounterResolve` / `treacheryRule` +
  `roundEnd` 读点），两章 behavior 只保留章节流程。

**04299 瓦卢西亚之子** —— 维度：`primitives`
- 卡面：「显现 - 将瓦卢西亚之子放置入场，放在密谋牌库旁。每个蛇族敌人得到 +1 攻击值和 +1 躲避值。
  强制 - 当一轮结束时：从场上弃掉 1 张瓦卢西亚之子。（每轮最多一次。）」
- 实现未走已登记原语：`docs/card-model.md §7.1` 明确「放在密谋牌库旁」统一为
  `state.agendaAside`（`api.putNextToAgenda` / `api.discardAgendaAside`，04094 等已接入，前端有
  「密谋牌库旁」卡堆与公开区域弹窗）；`theDepthsOfYoth/behavior.js:143,398-411,427-434,552-563` 却自造
  `state.scenarioZones.childrenOfValusia`（卡号数组）计数；卡牌没有实体实例，+1 攻击/躲避按数组长度而非
  场上卡实例，桌面上只能通过 `src/cards/campaign-view.js:111-122` 的自定义 `depths.childrenOfValusia`
  显示，无法进入既有密谋旁卡堆 UI。
- 证据：上述代码位置；`tests/acceptance-04-a-shard3.test.mjs` 之外的既有测试
  `tfa-depths-of-yoth.test.mjs`「04299 瓦卢西亚之子：每张副本各 +1 战斗/躲避，轮末弃 1 张」验证了计数语义，
  但验证不了「实体卡在密谋牌库旁」。
- 建议：改为 `api.putNextToAgenda` + `treacheryRule.discardOneAtRoundEnd`（card-model §7.1 现有读点），
  并把 +1 攻击/躲避改读 `agendaAside` 实例数；前端无需新写。
