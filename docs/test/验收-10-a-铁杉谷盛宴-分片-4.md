## 3. 失败明细（8 张，未实现子句）

### 3.1 10109 毛皮货 —— 两条印刷子句均无读点

- 「毛皮货在你手牌中时，你的手牌上限减少 3 张」：条目写成 `modifiers: [{ target:'handSize', amount:-3, condition:{sourceInHand:true} }]`，
  `modifierTotal(state, inv, 'handSize')` 能读到 -3，但 `src/engine/stats.js:234-255` 的 `handSize` 只读
  `passive.handSizeBonus`／威胁区／调查员规则，**从不调用 modifierTotal('handSize')** → 手牌上限实际不变。
  既有 P6 用例只断言 `modifierTotal === -3` 与 `note` 文本，未验证 `getHandSize`，属「断言修正源而非卡面行为」。
- 「游戏结束或你撤退时若仍在你手牌中：下一次购卡经验 -1」：`finishScenario` 只扫 `traumaAtGameEndWhenInHand`，
  `purchase-discount.js#grantPurchaseDiscount` 只有 api 出口、没有调用者，撤退/结局均无描述子触发窗口。
- 修法：`stats.js#handSize` 并入 `modifierTotal(state, inv, 'handSize')`；新增「结局/撤退扫描手牌」钩子（或
  `traumaAtGameEndWhenInHand` 同族字段）调用 `grantPurchaseDiscount`；补真实引擎用例断言 `getHandSize` 与折扣记录。

### 3.2 10117 飞斧 —— 附属敌人被击败时取回的反应未实现

- 攻击 +敏捷/+1 伤害、击败即弃、否则失去控制并附属到被攻击敌人均已实现（`api.fight addSkill`、`api.attachControlledAsset`）。
- 缺：敌人身上的玩家卡反应「所附属敌人被击败时：控制飞斧，所在地点任意调查员可触发」。引擎 `descriptorSources`
  只枚举手牌/受控支援/威胁区等，**`enemy.attachments` 里的玩家卡不是能力来源**；敌人离场时
  `hosted-assets.js#discardHostedAssets` 把飞斧弃到控制者弃牌堆，而不是让任意调查员取回。
- 修法：为 hosted 玩家附属补「敌人被击败」窗口来源与取回动作（原语），再补真实引擎回归。

### 3.3 10118 百折不挠 —— 弃牌堆投入未实现

- 条目 `abilities: []`。引擎 `tests.js#commitCandidates` 只扫手牌 + `playChannels`（beneath/playCommit/attachedCommit/
  deckTopCommit），没有「弃牌堆技能牌可投入」通道，也没有「投入后洗回牌库」档案字段；手牌投入按 [wild] 图标正常。
- 修法：新增弃牌堆投入来源 + `commitOrigin` 记录「投入后洗回牌库」，补真实检定用例。

### 3.4 10123 求生技术 —— 模式 1 未实现

- 模式 2（地点/地点附属诡计检定 +2 技能值）完整；模式 1「[fast] 选择一张附属在你地点且归你所有的卡牌并横置求生技术：
  将该卡加入手牌」完全未实现：`state.playerLocationAttachments` 无「取出到手牌」写入口。
- 修法：补 `playerLocationAttachments → hand` 原语，再补模式 1 用例。

### 3.5 10135/10136/10137/10138 —— 威胁区「不能离场」无读点

- 四张的显现二选一、-1 生命/神智、`[action][action]` 弃掉均实现；缺「除该能力外不能离场」。
- 引擎其实已有读点：`harm-threat.js:116` 检查 `registeredEntry(threatCard.code)?.cannotLeavePlay === true`，
  `asset-departure.js:9-11` 同样读 `entry.cannotLeavePlay`；但四条目均未声明该字段 → 任何「弃掉威胁区一张卡」的效果都能移除。
- 修法：四条目补 `cannotLeavePlay: true`（或 `threatEffect.cannotLeavePlay` 口径）并补「其它弃卡效果被拒绝」的真实用例。
