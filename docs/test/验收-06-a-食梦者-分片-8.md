## 3. 逐卡失败清单

### 3.1 实现完整性失败（5 张）

**06286 神居之所（剧本参考卡）** —— 维度：`implementation`；同时属「测试假绿」复核项。
- 卡面（`cards-data` 06286 text/backText）：
  - Easy/Standard：「[elder_thing]: **0**。The black cat reminds you that it's all a dream.」
  - Hard/Expert：「[elder_thing]: **-1**。……」
- 实现：`content/campaigns/theDreamEaters/scenarios/whereTheGodsDwell/chaos.js:36` 只匹配
  `token === 'elder_thing'`（带下划线）；而引擎/混乱袋实际 token id 是 **`elderthing`**（小写无下划线），
  依据：`content/campaigns/theDreamEaters/tde-chaos.js:13-14`（「token 面值与引擎一致……
  `skull/cultist/tablet/elderthing`（小写、无下划线）」）、`tde-chaos.js:206`
  （`whereTheGodsDwell` 的符号表含 `elderthing`）、`tests.js:912` 的符号枚举。
- 后果：`behavior.resolveChaosToken(state, inv, 'elderthing')` 返回 **null**，引擎
  `src/engine/treachery-tokens.js:358-367` 回落到 `SYMBOL_DEFAULTS.elderthing = -3`
  （`content/campaigns/nightOfTheZealot/shared.js`）——简单/普通应为 0、困难/专家应为 -1，
  即**两种难度都错成 -3**（直接影响全章所有含 elderthing 的检定）。
- 测试假绿：`tests/tde-scenario-whereTheGodsDwell.test.mjs:357-370` 断言时传的字面量是
  `'elder_thing'`，与引擎实际 token id 不同，因此既有测试通过但未覆盖真实路径。
- 复现：`node artifacts/acceptance/06-a-8/scan-wiring.mjs` + 新测试「06286 混乱标记表……」中
  `assert.equal(behavior.resolveChaosToken(state, inv, 'elderthing'), null)`。
- 修法（主进程）：把 `chaos.js` 的 case 改为 `'elderthing'`（可同时归一化 `elder_thing` 别名），
  并同步修正既有测试的字面量与 `definition.tokenMeanings` 的键（若确认键名也需对齐）。

**06289 混沌化身（议程 3 背面）** —— 维度：`implementation`。
- 卡面：`Each investigator is defeated and driven insane.`（`cards-data` 06289 backText）。
- 实现：`src/cards/encounter-entries/theDreamEaters/whereTheGodsDwell/06289.js:55-64` 的
  `agendaRule.onReveal` 只循环 `api.defeat?.(inv, 'chaosIncarnate')` 并写日志「被击败并发疯」；
  **没有调用 `api.driveInsane`**（引擎读点：`src/engine/scenario-runtime.js:1501-1514` 会给
  战役记录写 `record.status='insane'`、加满精神创伤、写 `drivenInsaneInvestigators`）。
  TDE 战役流程/本章 `resolution`（`behavior.js:688` 的 `scenarioResolution`）也没有把
  「被击败」映射成 insane 的兜底（全仓 TDE 仅 weaverOfTheCosmos、whereTheGodsDwell 的
  `hiddenMention` 调用 `driveInsane`）。
- 后果：该结局后调查员在战役记录里不会成为 `insane`（`insane` 状态决定后续能否继续战役/尾声走向）。
- 新测试「06289 混沌化身 背面……」锁定当前实现只 defeated、不发疯，作为缺口证据。

**06312 荒土蠕虫** —— 维度：`implementation`。
- 卡面：`Prey - Lowest [agility].`（06312 text）。
- 实现：`definition.js` 经 TDE `card-data.js#printed()` 写入的是**印刷短语** `'Lowest [agility]'`
  （`content/campaigns/theDreamEaters/card-data.js:76-79/317`）；而引擎猎物排序表
  `src/engine/card-ops.js:40-85 PREY_RANK` 的键是 camelCase（`lowestAgility` 等），
  `preyTarget()` 用 `PREY_RANK[enemy.prey]` 求值 → 印刷短语不命中 → `rank` 为 undefined，
  猎物退化为「所有候选并列、由队长任选」，**并非卡面的「敏捷最低」**。
- 同类实现约定：05088/05101/06084/06106/06107 等条目都用 `enemyRule.prey: 'lowestAgility'`
  覆盖印刷短语（TDE weaverOfTheCosmos 也如此）；06312 条目未写。
- 新测试「06312 荒土蠕虫……」在断言生成点/猎手的同时锁定 `entry.enemyRule?.prey === undefined`。

**06313 无面欺诈者** —— 维度：`implementation`。
- 卡面：`Prey - Most cards in hand.`；实现同 06312：definition 里是印刷短语，`PREY_RANK` 需要
  `mostCardsInHand`，条目未覆盖 → 猎物排序未接线。（其「攻击时手牌有混沌低语 → 揭示 +2 伤害」
  子句已正确接线并有既有测试 `tde-scenario-whereTheGodsDwell.test.mjs:597`。）
- 新测试「06313 无面欺诈者：猎物……」锁定缺口。

**06318 万千化身** —— 维度：`implementation`（该子句）/ `primitives`（死声明）。
- 卡面：`If no copies of Nyarlathotep attack as a result of this effect, Myriad Forms gains surge.`
- 实现：`src/cards/encounter-entries/theDreamEaters/whereTheGodsDwell/06318.js:55` 执行
  `api.setScenarioFlag?.('myriadFormsAttacked', attacked)`，注释称「涌动条件通过
  scenarioFlags.myriadFormsAttacked 交给章节 behavior.encounterGainsSurge 读取」；但：
  1. 全仓检索 `myriadFormsAttacked` **只有 06318.js 自己**（`artifacts/acceptance/06-a-8/scan-wiring.mjs`
     输出 `UNREAD: [{kind:'scenarioFlag', key:'myriadFormsAttacked', codes:['06318']}]`）；
  2. `whereTheGodsDwell/behavior.js` 没有 `encounterGainsSurge` 钩子（行为对象无该键）；
  3. 引擎 `src/engine/encounter.js:192` 的涌动判定读

- 后果：该子句永不触发（卡面字面功能缺失；且「声明了没人读」）。
- 新测试「06318 万千化身……」覆盖其余子句（揭示全部手牌复制品、逐张攻击、洗回遭遇牌库、
