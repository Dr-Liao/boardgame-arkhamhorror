## 2. 五维结论

### 2.1 实现完整性 —— **fail（53/57）**

- 53 张通过：每条卡面（含背面文本）子句都能在本地找到读点：
  - 调查员 5 张：托米（`assetDefeat` 原语 + `api.moveHarm` + 贝基 `uses` 真引擎验证）、曼蒂（搜索窗口额外 3 张真引擎验证）、托尼（`restrictedAction` 赏金专用额度真引擎验证）、卢克（开局自带门之匣真引擎验证 + `asIfEvent` 走 `as-if-location.js`）、派翠丝（`handSizeModifier`/`upkeepDraw` 读取点 + 旧印洗回走 `tests.js` 后续结算）。
  - 玩家卡 34 张：签名/弱点/绑定/进阶卡都有单卡条目读点；`searchedCardRule`（06008/06009/06023）、`hiddenEnemyInHand`（06017）、`attachedCommitAsIfInHand`（06024）、`connectsAttachedLocations`（06029）、`bondedShufflePlayCost`（06018/06024）、`onUsesEmptied`（06022）、`weaknessPlaysAsAsset`（06036）、`threatEffect.cannotTriggerActionAbilities`（06037）、`enemyRule.bearerCannotFightDamageDefeat`（06038）都在引擎有读点（`ability.js`/`moves.js`/`deck-ops.js`/`enemies.js`）。Dream-Gate（06015a/b）由 `dream-gate.js` 原语实现并被 `06013/06014` 直接使用。
  - 战役卡 18 张：参考卡混乱标记表/公开投影由 `chaos.js` + `viewState` 读点；议程 `doomKeptOnAgendaAdvance`/`agendaRule.forced`/`doomPlaced`（章节 behavior 分派）；幕 `actRule.onReveal`/`objective`/`chapterFlow`（`reveal.js` → `behavior.actReveal`）；地点 `locationRule.onReveal/onEnter/onLeave/onTurnBegins/onMythosEnd/actions/performAction` 都有引擎或章节行为读点（逐条 grep 复核，见 §4.2 测试）。
- **4 张失败**（详见 §3）：
  - `06046`、`06048`、`06049`：卡面「必须先发现上层地点全部线索才能进入」写在 `locationRule.entryError`，但**全仓无该字段读点**——引擎移动校验只读 `scenarioBehavior.moveError`/`investigatorEntryError`（`src/engine/moves.js:438,979`、`engine.js:239`），本章 behavior 也没有 `moveError`；同章的 aThousandShapesOfHorror/darkSideOfTheMoon behavior 都实现了对应分派，唯独本章缺失。
  - `06049` 另有「场上每有一张未揭示的魔幻森林，本地隐藏值 +1」写在 `locationRule.shroudPerUnrevealedEnchantedWoods`；`06053` 的「调查时手牌每 1 张，本地隐藏值 +1」写在 `flags.shroudPerHandCardWhileInvestigating`——两处都依赖本章 `locationShroudModifier` 分派，但该函数在本章 behavior 中**不存在**（引擎只认 `scenarioBehavior.locationShroudModifier` 或 `locationRule.shroudModifier` 函数），动态帷幕因此未实现。
- 近似/简化披露核对：本章 `behavior.scenarioApproximations = []`、`scenarioGaps = []` 均声明为空——与上述 4 张「有声明无读点」矛盾，属账本/文档口径不实（见 §5 G1）。

### 2.2 原语设计 —— **pass（57/57）**

- R1 直写状态：本分片新增卡号不在 `audit/card-entry-compliance.json` 任何阻断项基线；`audit:entries` 通过（R1=112 存量、R2=0、R3=0）。

- R3 回合限制缺失：0；`06027`（每场 2 次）、`06039` 等限制均有 `limit` 数据与读点。
- 同句规则复用：调查员/玩家卡大量走既有原语（`assetDefeat`、`harmTransfer`、`cardCounter`、`restrictedAction`、`searchedCard`、`asIfLocation`、`hiddenEnemy`、`bonded`）；战役卡的地点通用规则（进入/离开/回合开始/神话结束/行动）复用 `locationRule` 通道，同类规则没有逐卡复制。
