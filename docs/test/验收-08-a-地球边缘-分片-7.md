## 6. 原语与交互专项发现

1. **EOTE 数据声明与引擎契约命名不一致**是主要根因：`enemyRule.spawn:'anyEmpty'` vs 引擎 `spawnAnyEmpty`；`threatHorrorSink` 写在 `flags` vs 引擎条目顶层；`locationRule.flags.*` 与 `actRule.actTwoActions[].action` 只有数据没有分派实现。建议主进程在 `src/engine` 侧补通用读点或在章节 behavior 补 action 分发表，并给 `audit-eote-all-cards` 增加「声明键无读点」检测（当前账本把 24 张记为 no-test-evidence，未发现这些真实缺口）。
2. **08649 待原语**：地点背面「不能进入/不能有附属」需要通用 location back-face 限制读点（`primitive-requests/p7-08649.json` 未实现），与本分片 blocked 记录一致。
3. **08631 语义错误**：把「花费的 0 钥匙作为混乱标记加入」近似成 `addFrostToken`，属未披露替换，需按卡面修正（若引擎无「钥匙作混乱标记」原语，先补原语）。
4. **08651/08652 look**：只有日志、无观察投影读点；若布局层默认公开所有地点名称需显式说明等价，否则需补 `look` 投影。
5. 死声明（不单独判失败、随失败卡修复）：08648 `flags.tokenMeanings/sealAwareToken/towerAwareToken`、08650–52 `flags.roomSeal`、08642 `enemyRule.parley`。
