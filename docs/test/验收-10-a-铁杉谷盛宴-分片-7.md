## 6. 原语与交互专项发现

1. **失败窗口原语缺失（高频）**：地点/敌人的「攻击失败→伤害」「躲避失败→失去行动」「调查失败→恐惧」「近战成功后自伤」在本章 behavior 中只有旗标、无 `skillTestResult` 读点（P8 待接），共 5 张失败卡因此产生。
2. **运行时 API 缺口**：10586 依赖 `api.isDarkLocationHere`、10578 依赖 `api.revealChaosToken/drawChaosToken`，两者在 `scenarioRuntime` 均不存在 → 卡面效果恒失效（full-scan P1-4 未修）。
3. **待补原语**：10585 敌人附属到[[道具]]支援/文本空白规则（引擎无通道）、10587 显现附属目标选择与 [action] 弃卡地点条目通道。
4. **HEAD 已修复确认**：P0-2 无 seat choose（theLostSister pickTarget 已传 seat）、P0-5 寂静荒野裁决（`flagIs(...defeatAfterAttack)`）、双面敌人走 `flipHybrid/applyPhysicalFace` 单一实现。
5. **账本口径**：FHV ledger 对本片 13 simplified + 30 scenarioData + 2 scenarioReference，未区分「数据型已由 behavior 承接」与「子句未生效」；本报告判出 11 张未通过。建议主报告登记「FHV 账本去假绿 + 声明键/窗口读点检测」，本轮不重签账本。
