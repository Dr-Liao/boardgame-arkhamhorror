## 3. 失败明细（2 张）

### 3.1 09510 伦敦雨街 —— 强制补线索永不触发（卡号/实例 id 混用）

- 卡面：「伦敦雨街得到 +X 隐藏值（X=当前幕编号）；强制 - 如果伦敦雨街没有线索：在上面增加线索，直到其有
  1[每调查员]个线索；[action]：撤退。」
- 隐藏值 +幕编号已实现（`locationShroudModifier`，实测第 3 幕 = +3）；撤退行动已接（`riddlesResign`）。
- **缺陷**：`behavior.js:196` `const location = locationOf(state, RAW.rainyLondonStreets)` —— `RAW.rainyLondonStreets`
  是卡号 `'09510'`，`locationOf` 只按 `location.id` 匹配（实例 id 为 `'rainyLondonStreets'`）→ 永远返回 0；
  `locationRevealed` / `cluesRemoved` / `locationEntered` 三个钩子全部空转。实测：线索置 0 → `refillRainyLondonStreets`
  返回 0、线索仍 0（用例已把缺陷行为固化为断言）。
- 修复：改为 `locationOf(state, 'rainyLondonStreets')`（或支持按 code 查找），并补「发现线索后归零→自动补回」真实用例。

### 3.2 09518 戴红手套的男子 —— 幕 4 谈判 `api.test` 签名错误，点击即崩

- 卡面：隐匿 1[per_investigator]、反击；幕 4 追加「[action]：谈判。检定意志或智力(5)。成功在他上面放置 1 资源」。
- 隐匿分配（1 + 1/人诱饵、揭露真身才生成）、反击、精英/生命 2/人/胜利 1 均实测正确；资源用 `bounty` 卡计数器 +
  `behavior.parleyResources`（条目 note 已披露近似）。
- **缺陷**：`09518.js:43` `api.test(inv.seat, skill, 5, { source: {…}, resolve: result => … })`；引擎签名
  `src/engine/scenario-runtime.js:859` 为 `test(seat, skill, difficulty, resolve, skillBonus, source, options)`，
  第四参必须是函数 → `tests.js:826` 调 `options.resolve` 抛 `TypeError: options.resolve is not a function`。
- 修复：`api.test(inv.seat, skill, 5, result => {…}, 0, { type:'scenario', action:'parley', code:'09518' })`。
