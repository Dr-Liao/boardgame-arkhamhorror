## 4. 失败明细（2 张）

### 4.1 07165b 魔鬼礁石的骇物 —— 多出未印刷的 +3[每调查员]生命值

- 卡面（中/英一致）：`生成 - 渔船所在地点。猎手。庞大。反击。不能进入[[洞穴]]地点。
  强制 - 将要被击败时：改为移除所有伤害并将其横置，本轮剩余时间不能重整（包括补给阶段）。`
  ——**没有**「+3[每调查员]生命值」；这句只印在 07164b（版本一）上。
- 条目 `07165b.js` 声明 `modifiers: [{ target: 'enemyHealth', amount: ({state}) => 3 * state.numInvestigators }]`
  并注释「07164b 与 07165b 印刷前四行完全相同」——与 cards-data 实际卡文不符。
- 实测（`artifacts/acceptance/07-a-4/defects-evidence.txt`）：2 人局从渔船地点生成 07165b，
  `enemyHealth = 12`（印刷 6，多 6）→ 战斗难度显著偏离卡面。
- 仓库测试 `tests/tic-middle-remaining.test.mjs:98-106` 把该修正同时断言给 07165b，与实现一起写错；
  `:113-123` 只覆盖 07164b 的正确生命值。修复需同一轮改条目 + 该测试，并补 07165b 生命值=印刷 6 的断言。
- 其余 07165b 子句（生成点/洞穴禁入/击败替代/横置/本轮不能重整）均有读点与用例，故失败仅限该数值。

### 4.2 07185 伏兵出水 —— 额外标记也作用于躲避（卡面仅攻击）

- 卡面：`强制 - 在你攻击淹没地点的敌人时，揭示混乱标记时：再揭示一个混乱标记（每次检定最多一次）。`
- 读点 `src/engine/tests.js#floodedAttackExtraTokenRule` 只判 `enemyId` + 敌人所在地点淹没 + 密谋牌库旁有 07185，
  **没有校验 actionKind**；而 `combat.js:723` 的躲避检定同样带 `source.enemyId`，于是躲避也触发。
- 实测（同证据文件）：同一淹没地点敌人的 attack / evade 两种 options 都返回 `true`（期望攻击 true、躲避 false）。
- 既有测试 `07185：攻击淹没地点的敌人…` 只覆盖攻击分支；`docs/campaign/theInnsmouthConspiracy/acceptance.md:159`
  已把「07185 仅攻击触发」列入待长期回归的非 HIGH 问题，与本轮结论一致。
- 修复：读点加 `options.source.label === '攻击'` 或 `actionKind === 'fight'` 判定，并补躲避不触发的真实用例。
